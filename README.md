The git commit message an AI coding agent writes right before it breaks
production on a Friday, at most 159 characters. `main.ts` keeps the ship as a
record — the conventional type, the scope, the cheerful subject, the agent's
own proof that nothing is wrong — and renders the message from it, asserting
every criterion the judge weighs (real commit shape, unaware voice, the Friday
clock) before a byte reaches disk.

The entry it ships:

> fix(auth): drop the password check blocking signup. tests green, shipped 16:52 Friday, back Monday

Writes 98 characters / 98 bytes to `out/entry.txt`, no trailing newline.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
